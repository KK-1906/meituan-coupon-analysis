# 美团优惠券投放提效分析

基于 2023 年上半年订单、领券、访问三张行为表（97.3 万笔订单 / 1,123 万张券 / 4.97 万领券用户）的优惠券增量价值分析，按「七步分析框架」组织，并映射到产品运营六模块。

## 核心结论

| # | 结论 | 关键数字 |
|---|------|---------|
| 1 | 券是交易的主要构成，但不是增长的质量来源 | 券订单占 58.2%、券 GMV 占 55.4%；核销率 5.06%，90.6% 的券过期；人均领券 226 张、人均核销 19 张 |
| 2 | 核销率由门槛决定，而非面额 | 无门槛 18.9% vs 100 元以上门槛 1.0%；6-10 元券占 58.5% 成本但 ROI 仅 3.70 |
| 3 | 券没有抬高客单价，只促成「当下下单」 | 券订单用券前客单 41.90 元 < 非券 43.95 元；仅 59.3% 券订单达到门槛 |
| 4 | 增量存在，但只有表面 ROI 的一半 | 面额口径 ROI 5.90（保守下界）；中性假设（自然转化 50%）下增量 ROI 2.95；30% 毛利率下增量利润约 −42 万元 |
| 5 | 补贴结构错配 | 72% 券成本投向本来就会复购的高价值用户；无门槛券 ROI 3.45 却占 45.8% 成本 |

## 优化建议（可量化部分）

- 把无门槛券预算的 30%（约 50.8 万元）转向 21-30 元门槛券：成本不变，券 GMV 约 +85.6 万元（+3.9%），券 ROI 5.90 → 6.14（**情景模拟，线性外推，非实测**）。
- 3 天到期「僵尸」满减券（约 257 万张、核销率 0.5%）延长有效期至 7 天并下调门槛。
- 高频低消费用户取消无门槛券、降低触达频次；高客单低频用户改投大额满减券。

## 口径说明（本版已修正）

- **GMV = 实付金额（Actual_pay）**，非优惠前成交额；优惠前金额用「实付+优惠」近似。
- **ROI 双口径**：面额口径 5.90 = 保守下界（成本被高估）；登记口径 11.53 = 乐观上界（成本被低估）。
- **多券订单 GMV 按券数均分归因**，避免重复计入；券型分析仅覆盖「有效券」。
- **过期率**用券状态字段（90.6%），未核销率（94.9%）是另一回事。
- **业务线**：按编码 D/A/B/C 分组分析，不对编码含义做解读（D 占 93% 行）。

## 方法说明

- **数据清洗**：订单按 Order_id 去重（一单可叠多券，行级汇总会把 GMV 从 3,939 万高估到 6,006 万）；券表剔除字符串 `NULL`、面额≥门槛的倒挂券与极端面额。
- **成本口径**：以核销券面额为主口径（369.7 万元，保守下界），并披露按 `Reduce_amount` 记录的登记口径（189.3 万元，ROI 11.53，乐观上界）。
- **增量测算**：情景法（自然转化率 30%-70%）+ PSM-DiD（匹配 6,697 对）交叉验证；DiD 含选择效应，仅作上限参考。
- **用户分层**：RFM 五分位八分群 + 券依赖度分层。
