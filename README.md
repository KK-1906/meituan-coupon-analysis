# 美团优惠券用户分层与投放效果分析项目
## 项目简介
基于美团优惠券领取、核销数据集，使用 MySQL 完成数据清洗、指标计算、RFM 用户分层，结合热力图分析优惠券面额、使用门槛对核销率、ROI 的影响，输出投放策略建议，为精细化优惠券运营提供支撑。

## 分析工具
- MySQL：数据清洗、指标统计、RFM分层打标
- Excel：指标汇总、数据透视
- 可视化：热力图，对比不同券方案的核销差异

## 分析流程
1. 数据预处理：异常值清洗、统一统计口径，区分多业务类型
2. 指标搭建：领取量、核销率、核销金额、成本、ROI（粗ROI）
3. 用户分层：RFM模型，采用四分位数划分高/中/低频、高/低消费用户
4. 券方案分析：面额 × 使用门槛热力图，定位影响核销的核心驱动因素
5. 策略输出：针对不同分层用户，给出差异化触达、小预算测试投放方案

## 核心结论
1. 优惠券**使用门槛**是影响核销率最主要因素，其次是面额；
2. 高消费低频用户ROI最高，但基数小、转化门槛高，适合小预算测试触达；
3. 高频低消费用户核销稳定，适合常规放量投放，保障基础营收；
4. 不同业务类型消费周期差异大，RFM阈值按业务分开计算，不共用一套标准。
